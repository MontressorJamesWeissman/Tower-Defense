## Key conventions established this pass

- **Manifest is the source of truth:** `public/data/asset-manifest.json`
  (generated by `scripts/gen-assets.mjs`), typed in `src/game/assets/manifest.ts`.
- **Drop-in workflow:** `PreloadScene` loads each manifest path; missing files
  fall back to a generated labeled placeholder under the same texture key, so
  dropping a real file at the path needs zero code changes.
- **Tinting:** emitter/rune/effect/trail textures are greyscale/white so the
  engine tints them per Charge at runtime (Charge colors preserved).
- **Animations:** declared in the manifest per spritesheet and registered
  globally as `"<assetKey>:<anim>"` (e.g. `enemy.grunt:walk`).
- **Asset files live under `public/`** so Vite serves them at the site root and
  copies them into `dist/` on build (verified: `dist/assets`, `dist/audio`,
  `dist/data` present).
